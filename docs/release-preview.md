# 早期公开预览说明

GEOScout 当前适合作为单用户、本机运行的研究工具试用。它连接 NCBI GEO，并可调用用户自己的模型服务来扩展检索和复核数据集。

## 已验证范围

- 创建课题、解析条件、运行、暂停、恢复、取消和课题切换。
- 样本级硬条件筛选；明确的实验策略优先于共享 protocol。
- 证据、GSM 合格子集和 Excel 导出与界面结果保持一致。
- 离线后端测试、前端单元测试和生产构建在发布前检查中通过。

## 发布边界

- 这是 research preview，不是稳定版，也不是准确率或召回率评测。
- 检索受 NCBI 查询和本地预算限制，不能保证穷尽 GEO 或发现所有相关数据集。
- “推荐”只表示通过当前规则和证据检查，不等于数据集适合论文结论；研究者必须打开原始记录复核。
- “待核实”是正常结果；没有推荐不表示程序失败。
- 模型、NCBI 网络、SOFT 可用性和数据集元数据都会影响结果。
- 本版本面向本机单用户，不应直接暴露到公网。

## 反馈方式

报告问题时请附：版本、原始课题文本、模式和预算、GSE accession、页面显示的证据与类别。不要提交任何 API key、完整 Authorization header 或包含凭据的日志。科学误判请同时说明哪条硬条件与哪个 GSM 证据冲突。
